# 2. The Tension-Configuration Relationship

## Definition
This concept posits that tension within the body is not a static problem to be “released,” but rather a signal indicating a mismatch between the body’s current configuration and its optimal state.  Releasing tension requires providing a *new* configuration that the body can adapt to.

## Explanation
Tension arises when the body is in a position that’s not naturally supportive or efficient. Simply “relaxing” without understanding the underlying cause won’t resolve the issue.  You need to actively change the body’s alignment to allow the tension to dissipate.

## Key Insight
“You need to provide the body a new support which sometimes is a new tension.” – The core of this concept.

## Examples
The example of the car – needing a new support to allow movement – is a powerful illustration.  The speaker demonstrates this by using a rope to manipulate the body’s position and alleviate tension.
